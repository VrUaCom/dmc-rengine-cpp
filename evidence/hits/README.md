# HITS Evidence Records

This directory stores public, non-proprietary evidence metadata for HITS reverse-engineering promotions.

- `hits-pass8-wide-runtime-integration-review.evidence.json` — Pass 8 authority record linking the canonical executable hash, Drive preservation documents, retained findings, implementation freezes and remaining reverse targets.
- `hits-pass10-query-runtime-evidence.evidence.json` — Pass 10 machine-readable promotion for DMC3-profile HITS query-family identities, specialized call-site ABI observations, dynamic dispatcher/channel bindings, wrapper source boundaries, corrections, exact-build gating and cross-platform CI receipt. It explicitly preserves unresolved P0 result/arbitration ABI rather than filling it with product abstractions.

Raw proprietary HITS/PAC/EXE bytes are never stored here.
