# Support

DMC Rengine is an early-stage research and engineering project. There is no commercial support commitment.

## Where to ask

Use GitHub issues for:

- reproducible bugs;
- build failures;
- architecture questions tied to a concrete change;
- documentation gaps;
- feature proposals with scope and use cases;
- clean-room evidence submissions that do not include game files.

Use discussions or future community channels for broad ideas, mod concepts, lore, and general reverse-engineering conversation.

## Before opening an issue

Include:

- operating system;
- compiler and CMake version;
- commit SHA or release;
- exact command;
- relevant logs;
- minimal reproduction;
- whether local game files were involved.

Never upload proprietary game files. Replace paths and personal information where necessary.

## Not supported

The project does not provide game copies, cracked executables, DRM circumvention, leaked source code, or assistance redistributing copyrighted assets.
