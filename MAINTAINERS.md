# Maintainers

## Current repository owner

- **VrUaCom** — project owner and repository administrator.

## Maintainer responsibilities

Maintainers are responsible for:

- architecture enforcement;
- review and merge decisions;
- security reports;
- release integrity;
- legal/repository hygiene;
- Reverse Canon corrections;
- contributor access and conduct enforcement.

## Contact

Until a dedicated security or project email is published, contact the repository owner privately through GitHub for sensitive matters. Do not publish vulnerabilities, credentials, private game files, or personal information in public issues.

## Adding maintainers

New maintainers should demonstrate sustained contribution, sound technical judgment, respect for evidence rules, and willingness to maintain—not only create—project systems.
