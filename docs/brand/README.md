# DMC Rengine Brand Canon

This directory contains the public brand layer of DMC Rengine.

## Canon documents

- [Lore](lore.md) — The Order of the Inverted Triangle, Monks of Reverse, the Reverse Canon, Spider Hub, the Sealed Archives, and The Long Descent.
- [Naming System](naming-system.md) — canonical marketing and subsystem names.
- [Voice and Marketing](voice-and-marketing.md) — positioning, taglines, community ranks, visual language, and prohibited claims.

## Separation of concerns

Brand terminology may enrich interfaces, presentations, community pages, release notes, and onboarding. It must not obscure technical contracts.

Examples:

- `GDSpaces` remains the API and namespace name; **The Archive** is its marketing alias.
- `EXE Editor` remains the product name; **The Scriptorium** is its lore alias.
- `Binary Inspector` remains the product name; **The Reliquary** is its lore alias.
- `Stage Ops` remains the product name; **The Theatre** is its lore alias.
- `ModViz` remains the product name; **The Observatory** is its lore alias.

Technical code, schemas, tests, and APIs must always use canonical engineering names.

## Canon status

The technical product names predate this repository and are treated as established project canon. The Order, monk ranks, mottos, and extended mythology in this directory define the new public C++-era brand canon created for the open repository.
