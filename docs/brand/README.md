- **Sect of Neuroslop** = the wider DMC Rengine community.
- **Monks of Binary Code** = creators and evidence-backed recognized core contributors.
- **Order of the Inverted Triangle** = lore-facing alias for the core DMC Rengine Team.
- **Monastery of Binary Code** = lore-facing name for the DMC Rengine Core Development Hub.
- **The Long Descent** = the narrative journey from surface behavior to recovered source.
- **The Return** = behavior-tested recovered source entering a controlled build.

## Separation of concerns

Brand terminology may enrich interfaces, presentations, community pages, release notes, campaigns, profiles, and onboarding. It must not obscure technical contracts or duplicate canonical entities.

Examples:

- `GDSpaces` remains the API and namespace name; **The Archive** is its lore alias.
- `EXE Editor` remains the product name; **The Scriptorium** is its lore alias.
- `Binary Inspector` remains the product name; **The Reliquary** is its lore alias.
- `Stage Ops` remains the product name; **The Theatre** is its lore alias.
- `ModViz` remains the product name; **The Observatory** is its lore alias.
- A Sect member remains a community participant; Sect identity does not grant repository or platform permissions.
- A Monk of Binary Code remains a contribution-recognition title; explicit roles still govern access.
- Chambers remain tool aliases; they are not Teams, Orders, or resource authorities.

Technical code, schemas, tests, APIs, security controls, legal text, and stored workflow state use canonical professional names.

## Public/private boundary

The public repository contains the developed fictional lore and its operational safeguards. Private personal history behind the earliest naming is not part of the public brand canon and must not be added to repository documentation, issues, release notes, or marketing copy.

## Canon status

The technical product names predate this repository and remain established project canon. The Sect, Monks of Binary Code, core Order, Monastery, mottos, campaigns, rituals, and extended mythology in this directory define the public C++ repository lore.

All references to a Sect, Order, Monks, Monastery, doctrine, ritual, heresy, chamber, or Canon are fictional brand language. DMC Rengine is an open technical research and modding project, not a religious or coercive organization.
