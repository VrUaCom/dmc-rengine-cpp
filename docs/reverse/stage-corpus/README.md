# DMC3 stage corpus reverse notes

This directory contains documentation-only reverse notes for the extracted DMC3 `st*` stage corpus. Game assets, executables, and private absolute paths are intentionally excluded.

The detailed byte validators and JSON evidence remain in the local F-drive reverse workspace. The notes record parser authority, confirmed fields, corpus counts, and known variants.

See `FORMAT_COVERAGE.md` for the current boundary between test-verified formats and candidate/opaque families.
