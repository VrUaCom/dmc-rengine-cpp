# SEO Wave 4 Research — Character, Weapon and Blender Intent

Date: 2026-09-09

## Why this wave exists

After SEO v3.1 promoted unpacker, archive, character/enemy-model and Android-reader search surfaces, the next public search review showed useful adjacent intent around named character assets, weapons and Blender workflows.

The fourth wave therefore targets user problems that are meaningfully distinct from the existing general model page:

- Vergil model / Vergil textures;
- DMC3 weapon models, including Yamato, Rebellion, Beowulf and Force Edge searches;
- DMC3 Blender import / DMC3HDC Import Tools / DMC3 MOD, SCM and MOT Blender workflows.

## Community-tool boundary

Two independent public GitHub projects were verified as relevant community references:

- `deshayu/DMC3HDC-Import-Tools`;
- `HansLichtner/DMC3-Blender-Import-Addon`.

They are not part of DMC Rengine. Their presence supports the reality of the Blender-import search intent, not a claim that DMC Rengine itself provides Blender import/export.

## Funnel mapping

```text
named character / weapon / Blender problem
  -> practical guide
  -> DMC Rengine extraction / provenance / typed inspection
  -> canonical MOD / SCM / MOT / DDS / PTX research
  -> independent community DCC tooling where appropriate
  -> DMC Rengine ecosystem identity
```

## Acceptance boundary

Wave 4 must not claim:

- a universal Vergil or weapon filename/path without corpus evidence;
- that every weapon resource is a standalone MOD;
- native DMC Rengine Blender import/export;
- complete MOT authoring because a community tool can import MOT;
- original-game acceptance of edited or rebuilt resources without a runtime proof gate.

The goal is to answer real search language while preserving the project's evidence hierarchy.
