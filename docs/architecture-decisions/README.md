# Architecture Decision Records

ADRs record decisions that materially affect long-term architecture, governance, licensing, deployment, or compatibility.

## Index

- [ADR-0001 — Defer GUI Technology Selection](ADR-0001-ui-deferred.md)
- [ADR-0002 — Initial MIT License](ADR-0002-mit-license.md)

## Process

1. Copy the next numbered ADR.
2. State context, decision, consequences, and review triggers.
3. Link relevant specifications and pull requests.
4. Mark replaced decisions as superseded rather than deleting them.

Canonical constitutional rules remain in `.specify/memory/constitution.md`. ADRs explain concrete decisions under those rules.
