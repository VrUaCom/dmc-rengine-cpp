## Confirmed resolver policy

### Candidate construction and provider order

- lookup starts from request basename;
- recovered prefixes: `GDataX360.afs/`, `GData.afs/`, `Video/`, `afs/sound/`, `SAVEDATA/`, empty;
- archive attempts complete before physical attempts;
- archive normalization uses `0x0E`;
- physical normalization uses `0x0C`;
- candidate attempt remains the outer precedence authority.

### Archive provider

- original ZIP/NBZ backend owns a normalized sorted lookup representation;
- archive lookup uses recovered `0x0E` qsort/bsearch semantics;
- `.index` files are not runtime authority;
- comparator has no semantic secondary tie-break for equal normalized keys;
- GDSpaces preserves distinct equal-key identities as explicit ambiguity;
- real `DMCL-0.nbz` evidence has 1,095 unique normalized keys / zero collisions, but it is not a substitute for the DMC3 retail gate.

### Volume bootstrap

- `DMC3-%d.nbz` discovery is contiguous and first-gap bounded;
- physical mount is registered first;
- numbered archives are prepended, yielding highest contiguous volume down to zero precedence;
- zero-volume bootstrap reaches the physical phase directly.

## Physical provider — corrected state

Direct reverse of canonical `e454272e...` establishes:

- type-0 registration `0x140326D20`, normalization flags `0x0C`;
- resolve `0x140327430`;
- bounded root join `0x1403272C0`;
- existence helper `0x140327720` -> `FindFirstFileA` / `FindClose`;
- final open `0x140327800` -> `CreateFileA(path, GENERIC_READ, FILE_SHARE_READ, NULL, OPEN_EXISTING, 0, NULL)`;
- open errors 2/3 are normal miss;
- existence errors 18/2/3 are normal miss;
- no additional game-side case-folding/qsort/bsearch stage after `0x0C`.

The old index-only product physical model exposed a concrete case-semantics gap. The current branch therefore adds an optional `IDirectPathSource` capability. `LocalDirectorySource` uses source-native path lookup and returns the actual mounted-source `ResourceRef`; sources without that capability retain the explicit `product_physical_index` fallback.

Evidence classes remain distinct:

- `recovered_archive_index` — original archive lookup shape is directly recovered;
- `product_physical_native_path` — native product physical lookup;
- `product_physical_index` — compatibility index fallback.

No physical product class is relabeled as recovered/original-equivalent merely because the original Win32 contract is known.

## `OpenGameResource` caller / overflow closure

Direct caller census for `0x14002FCA0` found:

- `0x14003340A`;
- `0x1403380C7`;
- `0x1403381F7`.

All three pass `EDX = 1`.

For that mode:

- basename + six-prefix policy is active;
- archive mask `1` runs before physical mask `2`;
- candidate builder capacity is `0x400`;
- build failure releases the newly allocated file slot/object and returns `-1` immediately;
- no shorter prefix or physical pass follows overflow.

The first and longest prefix is 14 bytes, so a 1009-byte basename fits the 1023-byte text budget; 1010 bytes aborts the request.

## Remaining external blockers

### Retail DMC3 NBZ

`dmc3-0.nbz` is identified at 960,358,951 bytes. Both ordinary raw download and streamed-file-reference transfer are rejected by the current Drive connector at 268,435,456 bytes. No exact `dmc3-0.index`, member list or central-directory derivative was found.

### Protected distribution process

Prior audit identifies the protected distribution executable as:

- size: 6,567,320 bytes;
- SHA-256: `81c7e61983564113b5105e931d9f185accc14e44ae147d27f720c2d50935c7d6`;
- image base: `0x140000000`;
- entry point in `.bind`;
- high-entropy protected `.text` on disk.

File Library currently contains only the 6,356,432-byte canonical analysis executables, not this distribution binary. Therefore original-process instrumentation first needs runtime/raw reacquisition and a proven L2 function mapping.

`preflight-dmc3-game-test` is not that proof: it only validates an exact recognized distribution build plus archive co-location and explicitly leaves archive pairing/original-game acceptance unproven.
