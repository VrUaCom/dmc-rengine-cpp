## PR #219 reverse/integration model

### Child acquisition

`capture_main_module_window(pid, rva, size)`:

- accepts one explicit PID;
- max range `0x1000`;
- Windows only for live capture;
- `QueryFullProcessImageNameW` identifies process image;
- Toolhelp first module must resolve to the same normalized path;
- actual runtime address is `module_base + RVA` with overflow guard;
- `ReadProcessMemory` must return the complete requested range;
- partial reads fail closed;
- other platforms return `platform_not_supported`.

CLI `capture-exe-process-window` additionally:

- reads the discovered process image through GDSpaces;
- requires exact expected artifact SHA and size;
- parses PE headers and enforces `SizeOfImage` + one section/header range;
- records preferred image base and actual module base separately;
- emits a deterministic metadata receipt;
- can bind the live range to an expected canonical artifact/window hash pair;
- returns non-zero on expected-window mismatch while preserving negative metadata evidence.

### Multi-anchor promotion

`verify_l2_runtime_mapping_packet.py` will promote only when:

- every child is exact protected SHA/size;
- every child expectation is exact canonical analysis SHA;
- every live SHA equals its expected canonical SHA;
- no raw `bytes_hex` is present;
- all children belong to one PID/module/path session;
- all windows are `0x40` in `.text`;
- `OpenGameResource` RVA `0x2FCA0` is present;
- at least two independent physical anchors are present;
- duplicate/unapproved RVAs are rejected;
- output is no-replace.
