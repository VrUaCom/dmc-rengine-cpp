## Status language

- **implemented:** source and tests exist in the current repository;
- **initial implementation:** foundation exists but planned extensions remain;
- **approved for implementation:** scope is accepted, code is not yet complete;
- **planned:** direction exists but may still require architecture review.

## Completion rule

A specification is not complete solely because code exists. It requires tests, synchronized documentation/status, and compliance with the Constitution.
